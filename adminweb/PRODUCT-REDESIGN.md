# CFTP 管理后台 产品级重设计规格（Phase 3）

定位：不是换皮，是以成熟产品经理视角对**信息架构、工作流、跨模块衔接**的重构。
边界：所有后端 API 与请求契约不变；重构全部发生在前端表现层与交互层。
基础：Phase 1 已完成的设计系统（各版本 DESIGN.md）继续作为视觉规范。

---

## 一、全局产品模式（每个模块都要遵守）

### P1 实体链接（跨模块深度衔接的核心）
后台里所有对其他实体的引用，从"死文本"变成"可跳转的活链接"：
- 考试详情的「认证实例」→ 点击跳 `/prog?candidate=<考生ULID>` 并自动查询；「课程单元」保留 UlidChip。
- 认证实例卡片/详情的「考生」→ 各处考生引用统一可复制；订单/审核里的考生同理。
- 商品配置的「绑定认证」→ 跳 `/pipelines` 并把分类过滤预填。
- 资源包 → "查看文件" 跳 `/resource-pack-files?pack=<id>` 自动过滤。
- 落地方式：目标页面在 onMounted 时读取 route.query 里的预填参数（用页面**已有**的筛选字段与查询函数），自动执行一次查询。只用现有 API。
- 链接样式：正文色 + 下划线虚线 + hover 主色，带 ExternalLink/ArrowUpRight 小图标。

### P2 ULID 治理（UlidChip 组件）
- 新建 `src/components/UlidChip.vue`：等宽小字中间截断（前6后5），极浅底胶囊，title 悬浮全值，点击复制（Copy→Check 图标反馈 1.2s，@click.stop）。空值渲染 "-"。
- 全站所有裸 ULID / 确认号 / Object Key 长串一律 UlidChip 化；审计类页面需要完整值的场景用 mono 次级色。

### P3 详情结构化（消灭"假表单"）
- 只读详情一律用「定义列表瓦片」：极小 label + 值文本，ID 用 UlidChip，时间统一格式。
- 状态历史（考试状态流转、认证状态日志）→ **竖向时间线**：左侧圆点+连线（当前节点主色、历史节点灰），右侧事件标题+时间+哈希（UlidChip 化）。
- 阶段进行类数据（认证实例的阶段）→ **横向步骤条 Stepper**：已完成/进行中/未开始三态，进行中主色高亮。
- 原始 JSON 字段（如课程选择信息）→ 用 JsonPreview 折叠展示，不再塞进灰瓦片。

### P4 版本族分组（治"平铺几十个历史版本"）
适用：认证配置、商品配置、资源包配置。
- 前端按名称主干（去掉 " (Copy)"、"（副本）" 后缀后的名称 + 分类）分组：
  - 主行 = 该族最新的"已发布/草稿"版本，正常权重展示。
  - 其余版本收进「历史版本 N」展开行（点击展开显示历史版本子行，已下架/已废弃降权显示）。
- 纯 computed 实现，不改任何请求；展开状态本地 ref。
- 列表默认展示分组视图，保留原有筛选功能。

### P5 考生选择器（CandidatePicker 组件）
- 新建 `src/components/CandidatePicker.vue`：输入框 + 下拉搜索结果（姓名/邮箱模糊搜索，250ms debounce），数据源用**已有**的 `/api/dashboard/ops?user_keyword=&user_page_size=8`，结果行 = 姓名 + 邮箱 + 截断 ULID；选中后回填 candidate_ulid（v-model），并显示已选人卡片（可清除）。
- 替换以下场景的"裸 ULID 输入框"：考生权限管理的查询目标、订单管理筛选、考试管理筛选、认证管理筛选。原始 ULID 输入仍可用（组件里支持直接粘贴 ULID 回车即选）。

### P6 危险操作规范
- 删除/终止/清除类操作**不再**与常规操作并排铺文字链接：
  - 列表行：常规主操作(编辑/详情) + 「⋯ 更多」下拉菜单（新建 `src/components/RowMenu.vue`，含克隆/上下架/删除等次级与危险项，危险项红字+分隔线隔开）。
  - 详情/编辑器：危险操作集中到底部「危险操作」区或独立 Tab，红色描边卡片包裹。
- 确认弹窗保留并统一配方。

### P7 筛选体验
- 高频状态筛选做成**状态 chips 行**（点击即查，active 主色），替代或前置于下拉框；低频条件收进现有输入/下拉。
- 关键词输入统一 250ms debounce 自动查询（保留查询按钮）。

### P8 新增文案的 i18n 纪律
- 负责人统一在 zh.ts / en.ts 增加 `common` 命名空间（仅新增，不改不删既有 key）：更多操作/历史版本/危险操作/搜索考生/已选择/清除/展开/收起/复制/查看全部/暂无结果/先选择类型 等（负责人定稿约 20 个）。
- 页面 Agent 一律只引用 `t.value.common.*` 与页面既有 key，**不得**自行编辑 locale 文件、不得硬编码中英文。

## 二、模块级重设计

### M1 运营看板 → 运营驾驶舱
- 顶部加「今日待办」行:用已有 reddots 数据（/api/system/reddots）渲染待审核申请/考试/认证/订单/消息计数卡，点击直达对应模块（红点>0 才显示对应卡）。
- 保留统计卡/用户管理表/阶段分布/今日收款，但用户表的考生 ULID 用 UlidChip，用户行加 ⋯ 菜单占位（仅"复制 ULID"）。

### M2 审核中心 → 审核工作台（split-view）
- 布局改为左右分栏（lg 以上）：左侧队列（状态 chips: 待审核/已通过/已驳回/需重传 + 申请卡片列表，卡片=申请名+考生+提交时间+状态徽章），右侧详情面板（考生信息、材料清单与预览链接、历史意见）。
- 右侧底部**吸底操作条**：通过(主按钮)/驳回(危险描边)/要求重传(次级) + 审核意见输入。全部复用现有函数与状态。
- 小屏退化为列表+弹窗（现有形态）。空队列 → 正向空状态（"全部处理完毕"用现有文案 key，若无则仅图标+现有空文案）。

### M3 考试管理
- 筛选区：流程状态/成绩状态 → chips 行；考生 ULID 输入替换为 CandidatePicker；确认号/课程单元 ULID 收进"更多筛选"折叠区（Filter 图标按钮展开）。
- 表格：确认号与考试 ULID 全部 UlidChip；行整行可点。
- 详情弹窗：归属关系区的认证实例 → P1 实体链接（跳认证管理并按考生查询）；状态流转 → P3 时间线；同步考试结果按钮移入弹窗头部操作区。

### M4 认证管理
- 列表卡片重排：考生姓名为主标题，pipeline 名称次级，右侧状态徽章 + **迷你进度**（当前阶段序号/总数，用详情统计字段或现有字段），ID 全部收进次级行 UlidChip。
- 详情弹窗：顶部 hero 简化（考生 + pipeline 名 + 状态徽章 + 实体链接到考试管理按考生过滤）；「阶段」数据渲染为 P3 横向 Stepper；课程单元/状态日志保持 Tab，日志 → 时间线；人工操作移到底部操作区，「推进下一阶段」禁用时给出原因提示(title)，「终止认证」进危险区。

### M5 课程配置（最重）
- **列表**：状态 chips（全部/已发布/草稿/已弃用），已弃用行降权；行操作 = 编辑(主) + ⋯ 菜单(查看详情/克隆)；行整行点击进编辑器。
- **编辑器重构为 Tab 工作台**（同一页面内，现有数据与函数全部复用）：
  - 顶部：返回 + 课程名 + 状态徽章 + 版本号（面包屑感）；
  - Tab1 大纲：**章节→课时嵌套树**。每个章节一张可折叠卡片（章节名+排序+课时数徽章+章节操作），卡片内嵌套其课时行（课时名+类型徽章+操作），"新建课时"按钮放在每个章节卡片内（预填所属章节，若现有函数支持默认章节则传入；不支持则保持现有新建流程）。未归属课时集中在"未分组"卡片。
  - Tab2 课程资料：候选端辅助资料 + 普通文件资料两个区块（现有两块整合进一个 Tab）。
  - Tab3 测验题库：现有测验区块。
  - Tab4 课程信息：顶层表单（标题/描述/时长/高级配置）。
  - **吸底操作条**：保存(主)/发布(次)/删除(危险、右侧远离) + 未保存提示文案不新增（按钮状态已有 loading）。
  - 列表↔编辑器切换加过渡。
- 所有子表格 ID → UlidChip；资源链接可点击复制。

### M6 认证配置
- 列表按 P4 版本族分组（"CFtA Pipeline (Copy)(Copy)" 归入族内历史）；分类徽章保留。
- 编辑器：阶段列表可视化为纵向可折叠卡片（阶段→课程单元层级同 M5 大纲模式简化版）；危险操作按 P6。

### M7 商品配置
- 列表按 P4 版本族分组；主行信息层级：商品名 > 价格(tnum 加粗) + 状态徽章 > 绑定认证(实体链接)+ID(UlidChip)。
- 详情弹窗：hero = 名称+状态+大号价格；绑定认证 → 实体链接；其余定义列表化。

### M8 资源包配置 / 资源文件配置
- 资源包行操作收敛：编辑(主) + ⋯ 菜单（查看详情/克隆/上架/下架/删除-危险）；加"查看文件"实体链接 → `/resource-pack-files?pack=<id>` 自动过滤（文件页 onMounted 读 query 预填现有筛选）。
- 已废弃行降权。文件页 Object Key → UlidChip(不截断中间可用 mono 小字+复制)。

### M9 考生权限管理
- 「查询目标」的裸 ULID 输入替换为 CandidatePicker。
- 资格定义列表行点击 = 选中该定义（现有交互保留但行高亮明确），选中后查询按钮语义更清晰。
- 查询结果的权限项卡片化 + 操作按钮语义色（撤销类 danger 降权）。

### M10 站内信 / 邮件中心
- 站内信发送页改**两栏**（lg 以上）：左=收件人选择（顶部搜索输入过滤现有已加载列表 + 全选/清空 + "已选 N"徽章吸顶；行=首字母头像+姓名+UlidChip，选中高亮），右=模板/消息类型/Payload JSON（等宽字体+格式示例 placeholder 用现有 key）+ 发送按钮（未选人时禁用并显示原因 title）。
- 发送记录/模板管理 Tab 保持，表格升级（状态徽章、时间、UlidChip）。邮件中心同构处理。

### M11 事件与任务
- 左右布局：左侧**分组竖向导航**（5 组做成 rail：组标题+组内类型项，选中项主色高亮），右侧=当前类型说明+查询条件+结果表。小屏退化为下拉选择。
- 结果表 ID 全部 UlidChip；空态给引导文案（用现有 key 或仅图标+现有空文案）。

### M12 订单 / 发票
- 订单筛选的 Candidate ULID → CandidatePicker；业务类型/状态 → chips + 下拉混合。
- 订单详情：摘要 Tab 定义列表化 + 考生/商品实体链接；操作 Tab 的清除数据按钮进危险区卡片。
- 发票表格金额 tnum 右对齐、状态徽章统一。

### M13 审计日志 / PDF任务 / 证书模板 / 资格定义
- 表格化升级 + UlidChip + JsonPreview 折叠；筛选 chips 化（有状态维度的）。
- 资格定义/证书模板行操作按 P6 收敛。

## 三、实施纪律
1. 只允许调用页面**已有**的 API 函数与字段；新交互（行点击、菜单、链接跳转、分组、选择器）全部是前端组合，不发明新接口。
2. 组件复用：UlidChip / CandidatePicker / RowMenu 由负责人统一实现，页面只引用。
3. 不破坏移动端：分栏布局在 lg 以下退化为原单栏形态。
4. i18n 按 P8 执行。
5. 每页改完自查：无裸 ULID 直排、无并排红字删除链接、详情无假表单、状态历史有时间线/步骤条。
