## 已完成

1. **已发布课程的小修入口**：开放章节标题、课时标题和已返回正文的修改。章节排序、课时所属章节／类型／排序、媒体、外部课件及课时外链仍锁定；新增、删除、测验答案等结构变更只允许草稿操作。现有微服务允许的标题／正文更新直接修改当前课程版本，学员重新读取内容后可见，不承诺已经打开的页面自动推送刷新。
2. **安全的小修保存**：新增 `PATCH /api/lms/lessons/{lesson_id}/content`，只接受标题、可选正文及编辑开始时的真实版本号。BFF 读取对应课时，验证版本后调用已有 `UpdateLessonAdmin`，逐字段保留其媒体、外链、扩展 JSON 等原值；这是对完整更新协议的字段保留，不是推测或跨字段补值。没有返回课时、版本冲突或更新未确认时不会声称成功，也不自动重试。草稿仅修改标题／正文时同样使用此入口。
3. **富文本与分栏预览**：课时编辑区加入可视化编辑、HTML 源码、加粗／斜体／下划线、标题、列表、链接、HTTPS 图片和撤销／重做；正文旁实时预览。继续保存现有 `body` HTML 字段，不改变数据模型。预览对齐考生端 HTML 安全规则，不执行脚本／iframe／事件属性。自定义标签或属性不静默扁平化，明确要求使用源码编辑。
4. **课程目录**：课程编辑页和课时编辑面板显示真实章节／课时目录，可以在课时面板内切换课时。切换或关闭前如有未保存修改会提示；保存和上传期间禁止切换。章节及测验的详细表单仍使用既有编辑入口，未宣称已完成所有内容类型的同屏编辑器。
5. **草稿拖动排序**：章节排序及同章节内课时排序接入现有原子排序接口，也提供上下移动按钮。请求使用每条记录的实际 ID、版本和新的排序值；保存成功后重新读取目录，失败保留原展示并提示重新加载。缺少目录、ID、版本或排序字段时不生成默认值、不提交排序。跨章节移动不支持：现有 `UpdateLessonRequest` 没有改归属字段，编辑已有课时的章节选择框已锁定，避免产生“改了但没保存”的假象。
6. **创建草稿版本入口**：原“克隆”按钮改为“创建草稿版本”，仍使用已有复制接口；只有接口实际返回新的 Draft 课程及 ID 才进入其编辑页面。明确说明这是同一课程系列下的新草稿，发布不是学员迁移。
7. **状态缺失处理**：缺失 `status` 不再按 Draft 放开内容编辑／发布／删除；缺少必要编辑版本或排序值时提示不可操作，不传 0 或 1 冒充原值。上述新增文案支持中文、英文。
8. 新增课时小修接口接入现有管理员鉴权及 `update_lesson` 审计策略。
9. **2026-11-25 小修补充**：在现有课时面板内接入已保存 PDF 的签名地址预览，支持中英文、过期清理／重新加载、失败提示及切换课时清理。仅调用既有 `POST /api/lms/view-url` 读取授权，不修改课程内容或学习记录。此次未重构编辑流程。

## 数据缺口与禁止保底

- 完整目录必须实际返回 `chapters`、章节／课时 ID、排序和版本；缺失时显示不可获取。2026-11-25 已修正 BFF 对成功响应中真实空 repeated 列表的编码，空章节／空课时明确输出数组；缺实体仍报错，不补 ID、排序或版本。
- 草稿及发布后的课时正文缺失时均不会填空再提交；可单独改标题，正文保持服务端原值。正文缺失时不开放草稿的完整字段更新；正文实际返回且参与编辑时，文本课时必须保留可展示的内容。
- `version` 是已有接口的并发控制字段；界面不把该整数当作客户要求的独立“课程发布版本编号”。
- 本次未新增角色权限推断、学员迁移按钮或 Retire 假按钮。
- PDF 只加载同一已保存文件的实际签名 URL，缺 URL／对象不匹配／过期时报错；原始 URL 不写入正文。浏览器原生 PDF 阅读器的排版不等于考生端第三方阅读器，未宣称整个考生学习页面预览已经实现。
