## 2026-11-26 简版 Dashboard（待发布）

- 用户确认：收款不扣退款；按 UTC 零点统计今日收款，趋势取最近 24 小时与此前 24 小时的已完成订单金额对比。不同币种分别显示，不跨币种相加。
- 收款数据调用 gpay 的 `/gpay.PayService/ListOrders`，使用 `status_filter=ORDER_STATUS_COMPLETED` 与 `paid_at_from`（含）/`paid_at_to`（不含），按 UTC Unix 秒请求最近 48 小时内的订单。BFF 读取全部分页，按 `OrderSummary` 的 `paid_at`、`amount`（最小货币单位）及 `currency` 计算今日金额和趋势。该接口过滤能力来自 gpay 提交 `f1757624`；部署 Admin BFF 前需确保目标环境的 gpay 已部署此版本，否则旧服务可能忽略新增字段。
