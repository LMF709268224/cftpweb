## 本轮可补的接口输出，不属于保底方案

核对的是锁定共享依赖 `cftp@v0.0.0-20260921065505-a5bd1ca9cd04`、当前 BFF 及本地微服务源码，未声称线上已联调。

- `GetActiveMembership`：微服务 `gmbr/server/grpc_server.go` 明确在无记录时成功返回 `GetActiveMembershipResponse{}`。BFF 现在将该结果的 `Membership` 原值输出为 `membership: null`；整个响应为 nil 或 RPC 失败仍报错，不认定无会员。
- `/api/lms/enrollments`：protobuf 的 repeated 列表、`has_more` 布尔值、`progress_percentage` 数值均有明确契约。BFF 仅防止它们被 `omitempty` 省略，原样输出空列表、false 和真实 0。缺整个响应或列表中缺实体时报错，不编造记录、不统计首屏总数。
- `/api/lms/courses/{id}/complete`：服务成功返回完整课程后，空章节和空课时按真实 repeated 字段输出数组；课时 `body` 原值即使为空也明确输出。缺课程树、课程、章节或课时实体仍报错；不补状态、ID、版本或顺序。
- `/api/prog/pipelines`：此前清单误把它也列为 `has_more`／空列表省略。复查发现 BFF 原本已显式输出 `pipelines`、`has_more` 和游标，本轮修正文档，无需重复修改。
- `POST /api/lms/view-url` → `CreateViewURLAdmin`：已有管理员私有对象预签名读取能力，返回 `object_key`、`view_url`、`expires_at`。前端仅使用同一已保存 PDF 的返回地址；缺字段、对象不匹配、过期或请求失败均不加载预览，不拼接存储地址、不借用考生身份。预览不修改正文、上传文件或学习进度。
