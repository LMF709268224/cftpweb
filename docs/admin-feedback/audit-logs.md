# 审计日志反馈

依据本页底部中文意见，Web 端已完成以下调整（待发布）：

1. 将关键词、来源服务、操作、状态放进主筛选栏；操作人、资源类型、资源 ID 和时间范围收进高级筛选。
2. 来源服务下拉框展示业务名称。请求仍使用原有 `source_service` 值，避免改动审计接口的筛选语义。
3. 选择来源服务后自动刷新日志，并清空旧的操作条件。操作建议按该来源实际返回的日志动作展示；仍可手动输入准确动作值进行查询。

**尚需审计服务支持：** 第 3 条要求列出某来源服务的完整操作选项，并确保下拉项只包含该服务的动作。当前 `ListAuditLogs` 返回分页日志，Web 仅能收集已加载页面的动作，无法据此保证完整的 10–25 项清单。建议提供只读筛选选项接口，例如 `ListAuditActions(source_service)`，返回该服务可筛选的完整 `action` 值列表；若来源不固定，也可提供完整的来源与动作映射。接口应返回与 `ListAuditLogs` 筛选参数一致的原始值，展示名称可由 Web 映射。

本次只修改 Admin Web，未改微服务，也未部署环境。
