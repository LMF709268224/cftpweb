# 资格定义反馈

依据资格定义页的中文批注：

1. **复制配置：Web 已完成，待发布。** 列表增加“复制创建”，通过现有详情接口读取名称、分类、描述、获取方式和文件要求，再预填新建表单。新资源路径必须重新填写；原定义 ID 和参考附件不复制。
2. **显示哪条正在生效：待明确业务口径和接口支持。** 当前 `ListCredentialDefinitions` 仅返回 ID、名称、分类，`GetCredentialDefinitionDetail` 也没有状态、版本或生效标记。需要确认“生效”指资格定义本身启用，还是被当前已发布认证方案引用；确定后由对应服务提供权威状态或关联数据，Web 才能可靠显示。
3. **文件类型 Any：当前创建接口不支持。** `CredentialFileType` 中 `0` 是 `UNSPECIFIED`，Admin BFF 创建接口明确拒绝该值。当前 Web 新建表单只显示图片、PDF、视频、文本；复制旧定义时若遇到 `0`，会显示“未指定”并要求改选。若业务需要“接受任意类型”，微服务需定义并实现独立的合法类型及校验规则，再同步 BFF 和 Web。不能把 `0` 当作 Any 传入。

本次仅修改 Admin Web，未更改微服务，也未部署环境。
